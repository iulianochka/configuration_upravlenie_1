# Shell Emulator - Variant 16

Эмулятор командной оболочки UNIX-подобных ОС.

## Описание

Проект выполнен в рамках дисциплины "Конфигурационное управление".

## Этап 1: REPL

Базовый прототип с командами:
- `ls` - список файлов
- `cd` - смена директории
- `exit` - выход

## Структура проекта

- `src/` - исходный код
- `tests/` - тесты
- `scripts/` - скрипты запуска
- `vfs_data/` - примеры VFS

## Запуск

```bash
python src/main.py
